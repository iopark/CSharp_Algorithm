# CSharp_Algorithm

2023년 경일게임아카데미 부트캠프 C# 과정 (Week 1 ~ 6, 2023-04 ~ 05). 자료구조와 알고리즘을 직접 구현한 기록입니다.
Hand-written data structures and algorithms from the 2023 bootcamp C# track: List, LinkedList, Stack, Queue, Heap, BST, HashTable, Dijkstra, A*, MST, plus a text RPG.

- `Week 2/day08_Sokoban` — Sokoban with undo (Day 8 assignment)
- `Week 3/day16_` — console problems 1 to 8 (merged from the former `day16_` repo)
- `Week 4`, `Week 5`, `day_28_Task`, `day29_Task`, `day30_TextRPG` — daily tasks, with the assignment text next to the code
- `_05._Queue` … `_14._MinimumSpanningTree` — topic implementations
- `CSharp_Interview_Prep` — study notes

Class notes for every day: https://github.com/iopark/kyungil-bootcamp-2023-notes
